    Mapa de Google
    ¿Cómo obtengo la clave?
    1. Entra a console.cloud.google.com con tu cuenta de Google.
    2. Crea un proyecto y activa Maps JavaScript API (y Geocoding API para buscar direcciones).
    3. Ve a Credenciales › Crear credenciales › Clave de API y cópiala aquí.
    4. Recomendado: limita la clave a tu página (por ejemplo sebastindelqui-cloud.github.io/*).

    Google pide una tarjeta para verificar la cuenta; el uso personal entra en la parte gratuita.
